# 工业级零件设计标准（单零件）

本文件是单零件建模的**工业级设计规范**。它回答一个问题：**一个零件除了"形状对"，还缺什么才叫"工业级"而不是 toy？**

`cad-component-generation` 的特征清单负责"形状正确"（Sketch → Extrude/Revolve/Mirror/Fillet）；本文件负责"工程真实"（倒角、圆角、加强筋、退刀槽、配合面…）。**两者都满足才算工业级零件。**

---

## 0. 工业级 vs toy 的判定（先过这一关）

| 判定 | toy（禁止） | 工业级（要求） |
|---|---|---|
| 主体形状 | 一个裸 `Box` / `Cylinder` / `Sphere` 就是全部 | 主体形状 + 大量工程特征 |
| 功能分解 | 一个几何块代表一个功能部件（电机 = 一根圆柱） | 拆成真实内部子特征（电机 = 后盖 + 壳体 + 减速器 + 轴承 + 螺栓孔法兰，逐条建模） |
| 复杂外形轮廓 | 用直线+圆硬拼出流线型/有机形/需光滑过渡的外形 | 用 `Spline`/`Bezier`/弧/椭圆等曲线拟合光滑外形 |
| 管状/弯曲件 | 用直线管段 + 硬折角拼接 | 沿 `Spline`/`Helix`/折线路径 `sweep` 扫掠，转角自然过渡 |
| 空心结构 | 实心块 | 等壁厚抽壳（外体 − 内体）/ 空心管（外圆柱 − 内圆柱） |
| 锐边 | 所有棱角原样保留（直角） | 外缘倒角 `C0.3–C1`，内角/根部圆角 `R0.5–R3` |
| 安装孔 | 光孔直通，无沉头/倒角，孔位随手放 | 沉头/埋头/倒角，螺纹孔带凸台+退刀槽；螺栓孔按 `PolarLocations` 在 PCD 上均布 |
| 尺寸来源 | 尺寸拍脑袋（「大概 10mm」） | 标准件按标准（M3 通孔 Ø3.4、608ZZ 轴承 8×22×7），外购件按 datasheet |
| 承力 | 均匀壁厚，无加强 | 加强筋、凸台、加厚壁 |
| 配合面 | 无明确的精配合面 | 轴承座、轴肩、键槽等精加工配合面 |
| 减重 | 不考虑 | 非承力区减重孔/槽 |
| 制造痕迹 | 无 | 拔模角、退刀槽、工艺倒角 |

**自检口诀**：拿出你建的零件，问一句"这个能拿去车间加工/开模吗？"——如果答案是"这就是一块料"，说明还是 toy。

## 1. 通用工业特征清单

每个自建模零件，按下面的清单逐条核对，**该有的必须有**（不该有的不加，不能为了凑特征乱加）。

### 1.1 倒角（chamfer）—— 外缘必备

- **是什么**：在锐利外棱上切出 45°（或 C 值）小斜面。
- **为什么**：去除毛刺/锐边（伤人、刮伤、应力集中、装配卡滞），是加工件的第一道"文明化"。
- **什么时候用**：所有暴露的外棱、孔的入口、轴端、板件边缘。**没有特殊理由，外缘一律倒角。**
- **建模要点**：`chamfer(edges, length=...)`；常用 `C0.3–C1`（小件 C0.3，结构件 C0.5–C1）。倒角值要统一（全件同一 C 值），不要一个 0.3 一个 1.0。

### 1.2 圆角（fillet）—— 应力/根部必备

- **是什么**：在**内角**（两个面相交的凹角、筋与壁的根部、台阶根部）切出圆弧过渡。
- **为什么**：内角是应力集中源，直角内角容易开裂；圆角也改善铸造/注塑的流动。
- **什么时候用**：加强筋根部、凸台根部、台阶过渡、型腔内部转角。**内角圆角，外角倒角**（区分二者：外棱倒角，内角圆角）。
- **建模要点**：`fillet(edges, radius=...)`；根部圆角 `R0.5–R3`，与壁厚成正比（壁 3mm → 根部 R1 左右）。

### 1.3 加强筋（rib）—— 薄壁/承力必备

- **是什么**：在薄壁板、底座、支架的背面/内侧加竖起的筋条。
- **为什么**：用最少的材料换刚度，避免薄壁变形。
- **什么时候用**：壳体大平面、安装底座、长臂支架、隔板。
- **建模要点**：筋厚 ≈ 0.6–0.8 × 主壁厚；筋高 ≈ 2–3 × 筋厚；筋根部圆角（见 1.2）；筋端部倒角或斜收。筋要**连到承力路径**上，不能悬空。

### 1.4 安装凸台（boss）—— 螺纹紧固必备

- **是什么**：螺纹孔处的一圈加厚凸台。
- **为什么**：给螺纹提供足够的咬合长度，同时局部加厚承力。
- **什么时候用**：螺纹孔开在薄壁/薄板上的场合（螺钉直接拧进薄板会滑牙）。
- **建模要点**：凸台直径 ≈ 2 × 螺纹公称直径；凸台高度 ≥ 螺纹咬合长度（钢 ≈ 1.5d，铝 ≈ 2d）；凸台根部圆角；凸台顶面与螺纹孔同轴。

### 1.5 沉头/埋头孔（countersink / counterbore）—— 螺钉安装必备

- **是什么**：螺钉孔入口加工成锥形沉头（countersink，配沉头螺钉）或柱形沉孔（counterbore，配内六角螺钉）。
- **为什么**：螺钉头/螺母沉入表面，不凸出；也提供定位。
- **什么时候用**：需要螺钉头齐平/沉入的场合。
- **建模要点**：`Hole(countersink/counterbore)` 参数按螺钉标准（M3 沉头 ≈ Ø6.3×90°，M4 沉孔 ≈ Ø8）；不要画成一个光孔了事。

### 1.6 退刀槽 / 清根（relief / undercut）—— 螺纹与配合面根部必备

- **是什么**：螺纹末端、轴肩根部、磨削面根部切出的环形细槽。
- **为什么**：让螺纹刀具/砂轮有退刀空间，避免螺纹根部与台阶干涉；也让配合面能加工到位。
- **什么时候用**：螺纹到肩部、轴肩根部、需要磨削的精配合面根部。
- **建模要点**：退刀槽宽 ≈ 2–3 × 螺距，槽深略大于螺纹大径的槽底；轴肩根部退刀槽宽 ≈ 1–2mm。位置在**配合面与相邻面的交界**。

### 1.7 密封槽（seal groove）—— 密封场合必备

- **是什么**：配合面/端盖上的环形（或平面）凹槽，容纳 O 型圈或密封垫。
- **为什么**：密封件需要固定位置和压缩量，不能直接夹在平面上。
- **什么时候用**：端盖、法兰、壳体接缝需要密封时。
- **建模要点**：O 型圈槽按标准（槽宽/槽深 = 圈径 × 系数，压缩率 15–25%）；槽截面矩形带底部圆角。

### 1.8 减重结构（lightening）—— 大体积/非承力必备

- **是什么**：在非承力区域挖减重孔、减重槽、或做成镂空筋板。
- **为什么**：减重、省料、散热。
- **什么时候用**：大型支架、底座、连接块的非承力部分。**只减非承力区**，承力路径不能挖。
- **建模要点**：减重孔避开螺栓孔和力线；边缘留足够壁厚（≥ 2mm）；减重后仍要满足刚度（配合加强筋）。

### 1.9 拔模角（draft）—— 铸造/注塑件必备

- **是什么**：沿脱模方向的斜度（一般 1°–3°）。
- **为什么**：让零件能从模具/砂型里脱出来。
- **什么时候用**：压铸、注塑、砂型铸造的零件。**机加工件（数控铣）通常不需要**（甚至不能乱加）。
- **建模要点**：外表面沿脱模方向外张、内表面内缩；拔模角度 1°–3°；在特征清单里**先声明制造工艺**（机加工 / 铸造 / 注塑），再决定是否加拔模。

### 1.10 精配合面与定位特征 —— 有装配关系必备

- **是什么**：轴承座孔、轴肩、键槽、定位销孔、贴合面等**有公差要求**的配合特征。
- **为什么**：这些面决定装配精度和运动精度，是零件"有功能"的体现。
- **什么时候用**：零件与轴/轴承/齿轮/另一零件有配合时。
- **建模要点**：
  - 轴承座：孔 + 轴肩（定位轴承轴向）+ 卡簧槽或端盖。
  - 轴：轴肩（定位）、键槽（传扭）、中心孔（加工基准）、轴端倒角。
  - 贴合面：明确的配合平面，标注与接口契约一致。

### 1.11 装配间隙与防干涉 —— 有装配关系必备

- **是什么**：零件与相邻零件的空间关系——哪些面贴合（间隙≈0）、哪些面留间隙、活动件留运动间隙。
- **为什么**：零件不是孤立的，它要装进总装且不能与相邻零件互相穿插。toy 建模常忽略这点，导致装配时零件重叠/干涉。
- **什么时候用**：零件与另一零件有配合或相邻关系时（几乎所有的装配零件）。
- **建模要点**：
  - 接口契约里的「配合尺寸」必须带间隙：轴-孔是**间隙配合**（轴径 = 孔径 − 间隙），不是零间隙；活动件留运动间隙。
  - 区分**贴合面**（配合面，间隙≈0，用于定位/传力）和**非贴合面**（留 ≥0.2–0.5mm 间隙，避免装配干涉）。
  - 活动件留运动间隙（如旋转件与壳体之间留 0.5–1mm）。
  - 零件外形不要侵占相邻零件的包络——设计时对照 BOM 里相邻零件的接口契约和骨架站位（`plan.md` 第 2 章），确认不越界、不重叠。
  - 装配时最终以 `inspect interfere` 为准：`clashCount=0` 才算无碰撞无重叠。

## 2. 常见零件类型的工业级设计模式

按零件类型，给出"至少要有哪些细节"，作为产特征清单时的起点（不是全部，按实际需求增删）。

| 零件类型 | 工业级必备细节（除通用倒角/圆角外） |
|---|---|
| **轴类** | 轴肩（轴向定位）、键槽（传扭）、轴端倒角、中心孔、退刀槽（磨削面根部）、螺纹段+退刀槽 |
| **轴承座 / 孔座** | 轴承孔（精配合）+ 轴肩 + 卡簧槽/端盖安装面 + 安装螺栓凸台 + 底座加强筋 |
| **法兰** | 螺栓孔均布（带沉头/倒角）+ 密封槽 + 配合止口（凸台定位）+ 内外缘倒角 |
| **支架 / 底座** | 安装耳（带凸台孔）+ 加强筋 + 减重孔 + 主安装基准面 |
| **壳体 / 箱体** | 壁厚均匀 + 加强筋 + 安装凸台 + 密封槽 + 散热/减重结构 + 拔模（若铸造/注塑） |
| **齿轮 / 带轮** | 齿形（渐开线/梯形齿）+ 轮辐减重 + 轮毂凸台 + 键槽 + 齿端倒角 |
| **端盖** | 密封槽 + 螺栓孔 + 止口定位 + 轴承避让/压紧结构 |

## 3. 产特征清单时的强制顺序

写「特征步骤清单」时，按这个顺序走，确保工业级细节不被漏掉：

0. **拆功能件**：先问「这个零件在真实世界里由哪些子部件组成？」把它拆成可分辨的工程子特征，逐条列进清单（关节电机 → 后盖 + 编码器盘 + 壳体 + 减速器 + 轴承 + 输出法兰；连杆 → 两端叉耳 + 减重空心梁 + 螺栓孔法兰 + 轴承座 + 走线槽）。**禁止一个几何块代表一个功能件**。具体拆法范式见 `technique-cases.md`。
1. **定制造工艺**：机加工 / 铸造 / 注塑 / 钣金 —— 决定拔模角、最小壁厚、圆角半径。
2. **定主体形状**：Sketch → Extrude/Revolve 建主体。▲ **复杂外形（流线型 / 有机形 / 需光滑过渡）用曲线实体**（`Spline` / `Bezier` / `ThreePointArc` / `TangentArc` / `Ellipse`）拟合，**不要用直线+圆硬拼**；直线和圆只用于真正的直线边、圆孔、圆凸台。▲ **管状/弯曲件用 `Sweep`**（沿 `Spline`/`Helix`/折线路径扫掠截面），**有机渐变形用 `Loft`**（多截面放样），**空心件用 `Shell`**（外体 − 内体布尔）。
3. **加功能特征**：孔、键槽、密封槽、螺纹、退刀槽、配合面、螺栓孔环 `PolarLocations`（这些是"功能"）。
4. **加结构特征**：加强筋、凸台、减重（这些是"刚度/减重"）。
5. **加工艺/文明化特征**：外缘倒角、内角圆角、根部过渡（这些是"工程收尾"）。
6. **自检**：对照第 0 章 toy 判定表逐条过一遍。

**禁止**：先建一堆裸体素拼在一起，再"想起来"补细节——那样一定会漏。细节要从清单一开始就规划进去。

## 4. 反面示例（对照）

**toy 轴承座（禁止）**：一个带通孔的方块 `Box`。→ 没倒角、没加强筋、没凸台、没轴肩、没退刀槽。

**工业级轴承座（要求）**：
- 底座：矩形 + 底部加强筋 + 四角安装凸台（带沉头螺栓孔）+ 减重槽
- 轴承孔：精配合孔 + 轴肩（一侧定位）+ 另一侧卡簧槽
- 外缘：全倒角 C0.5，筋/凸台根部 R1 圆角

同样一个"轴承座"，工业级版本比 toy 版本多 5–8 个工程特征，这才是"真实零部件"。

## 5. 真实高精度参考案例

「工业级 vs toy」是**标准**，`technique-cases.md` 是**范式**——从已验收的「人形机器人 / 灵巧手 / 摩托车 / 自行车」工程里提炼的 5 个单零件拆解案例，直接照着拆：

1. **关节电机**（对应真实谐波关节 DM-J4340 的精细度）→ 后盖 + 编码器盘 + 壳体 + 谐波减速器 + 交叉滚子轴承 + 螺栓孔输出法兰，沿轴线堆叠。
2. **空心结构连杆** → 外体 − 内体抽壳 + 矢状加强筋 + 减重窗 + 螺栓孔法兰 + 双侧轴承座 + 走线槽。
3. **U 形叉耳支座** → 座凸台 + 叉板 + 轴承耳塔 + PCD 螺栓孔环。
4. **放样有机指骨** → 截断椭圆截面 `loft` + 球面指尖帽 + 桶形铰耳。
5. **样条扫掠弯管** → 圆形截面沿 `Spline` 路径 `sweep` 成空心车架管。

**拆功能件前必读 `technique-cases.md`**，不要自己发明粗糙做法。
