# 材质与颜色速查表

规划零件时，**材质**与**颜色**是两个必须一起落地的属性。材质是物理属性
（它决定壁厚、圆角、拔模、表面处理等设计决策）；颜色是渲染属性（它决定
最终 STEP/GLB 长什么样）。两者都应在**产特征清单 / 写零件表阶段**就定下来，
不要建完再补。

## 上色机制（必读，两条都静默失效）

- 用 `cadgen.srgb("#hex")` 赋色，**不要**用裸 `Color(r, g, b)` 猜通道——
  渲染器把 `Color` 通道当 **linear RGB**，`Color(0.5,0.5,0.5)` 显示出来是
  `#BCBCBC` 而不是 `#808080`，肉眼取 hex 会洗白发灰。
- **颜色只挂在叶子 shape 上**。设到 `Compound`/分组对象上的颜色进不了渲染包
  （只会写进 STEP 的 XCAF 标签，看起来像成功了）；每个叶子都要单独赋色。
  （详见 `build123d-modeling.md` 的「Colour」节。）

```python
from cadgen.color import srgb

part.color = srgb("#B4B8BE")            # 铝合金银灰
glass.color = srgb("#C8D0D8", 0.35)     # 透明件带 alpha
```

## 常见材质 → 推荐颜色

| 材质 | 典型规格/用途 | 推荐 hex | 备注 |
|---|---|---|---|
| 铝合金（本色） | 6061 / 7075，机加工件 | `#B4B8BE` | 银灰 |
| 铝合金（阳极氧化黑） | 壳体、散热件 | `#2E343A` | 深灰黑 |
| 铝合金（阳极氧化彩） | 装饰件 | `#8A9BA8` | 可按品牌色微调 |
| 钢 / 碳钢 | 45#、40Cr、Q235 | `#8B8D8F` | 铁灰 |
| 不锈钢 | 304 / 316 | `#C0C4C8` | 亮银 |
| 铸铁 | HT200 | `#5A5C5E` | 深灰 |
| 钛合金 | TC4 | `#6E7276` | 中灰 |
| 黄铜 / 铜合金 | H59 / 磷青铜 | `#B08D57` | 黄铜 |
| ABS（本色/白） | 注塑外壳 | `#E8E8E6` | 暖白 |
| ABS（黑） | 注塑外壳 | `#3A3A3C` | 黑 |
| 尼龙 PA6/PA66 | 齿轮、耐磨件 | `#F2E8DA` | 米白 |
| POM 赛钢 | 精加工件 | `#FFFFFF` | 白，可微透明 |
| PC 聚碳酸酯 | 透明罩、观察窗 | `#C8D0D8`（α≈0.35） | 透明 |
| 亚克力 PMMA | 透明件 | `#D8DEE4`（α≈0.25） | 透明 |
| 橡胶 / TPE / 硅胶 | 密封、缓冲、轮胎 | `#2E2E32` | 黑（软） |
| 碳纤维复合 | 结构件 | `#1E1F22` | 碳黑 |
| 电木 / 酚醛 | 绝缘件 | `#6B4A2E` | 棕 |
| 陶瓷 | 绝缘、耐磨 | `#F0F0EE` | 亮白 |
| 玻璃 | 观察窗 | `#B8C4CC`（α≈0.30） | 透明 |

- **import 的外购件/标准件**：保持库内自带材质色，不重新上色（除非用户要求
  统一风格），零件表颜色列写「库内」或「—」。
- **未列材质**：按「相近材质」取色，并在零件表 / 清单里注明 `[⚠️假设-待确认]`，
  不要随手编一个不相关的颜色。

## 功能子特征区分色（可选，多子特征零件用）

一个功能件拆成多个子特征（编码器/壳体/减速器/轴承/法兰）时，除零件主色外，
可用以下约定给子特征加区分色，让渲染图一眼看清结构层次：

| 功能 | 推荐 hex |
|---|---|
| 结构件 / 壳体 | 灰系（按材质取） |
| 执行器 / 电机壳 | `#3E6B8A`（蓝） |
| 减速器 / 传动 | `#5A7080`（蓝灰） |
| 轴承 / 精密环 | `#C9CDD1`（银） |
| 传感 / 编码器 | `#4A7A5C`（绿） |
| 密封件 / 橡胶 | `#2E2E32`（黑） |
| 紧固件 | `#8B8D8F`（钢灰） |

## 规划落点

| 场景 | 材质/颜色写在哪里 |
|---|---|
| 单零件（`$cad-component-generation`） | 特征清单开头声明「材质 + 主色 +（可选）子特征区分色」，代码里逐叶子 `srgb` 上色 |
| 装配体（`$cad-plan` 第 4 章零件表） | 每行写「材料/规格」+「颜色」两列，值取自本表 |
| 编排层（`CLAUDE_cad.md` 阶段 1/2） | BOM 标注材质颜色 → 单零件构建时落到 `.step.py` |
