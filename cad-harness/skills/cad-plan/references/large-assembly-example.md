# 大型装配体规划样板（L3 工程级）

> **用途**：本文件是一份**完整规模的 L3 样板**，用于校准「大型复杂对象该拆到什么程度」。
> `planning-template.md` 里的行星齿轮减速器示例演示的是**写法**（20 类，L1 档）；本文件演示的是**规模**（121 类，L2/L3 边界）。
> 做大型对象（运载器 / 整车 / 机床 / 产线设备 / 大型泵机组）时读本文件对齐颗粒度，**不要拿减速器示例的行数当参照**。
>
> 本文件只摘录规模相关的章（0 / 2 / 3 / 4 / 6 / 8）。第 1 / 5 / 7 / 9 章的写法见 `planning-template.md`，规模上不产生额外指导。
> 因此校验本文件须加 `--partial`；你实际产出的 `plan.md` 必须 11 章齐全，**不加 `--partial`** 也要 0 error。

> ⚠️ **数据免责声明**
> 本样板以公开出版物、用户手册与媒体报道为基础整理，用于演示 CAD 规划的拆解颗粒度。
> **所有几何尺寸、公差、自由度范围均为推测或假设值，不代表任何真实产品的设计数据**，一律标注 `[⚠️假设-待确认]`。
> 真实工程项目请以甲方图纸/规格书为准。

| 项 | 内容 |

## 2. 骨架与基准体系

> 大型回转体对象必须用**站位（Station）体系**：沿主轴向定义一系列基准面，所有零件按站位定位。
> 这是大型对象骨架与小对象最大的不同 —— 小对象几个基准面够用，大对象需要成体系的站位表。

```
CSYS_VEH                全箭基准
  原点 = 一级尾端理论面 ∩ 箭体轴线
  Z 轴 = 箭体纵轴，指向头部（正方向 = 飞行方向）
  X 轴 = 1# 发动机方位（相位 0°），同时定义栅格舵/着陆腿相位基准
  Y 轴 = 右手系补足
```

## 6. 自由度与耦合（大对象写法节选）

> 重点演示**多杆机构不许简化**。

| 部件 | joint 类型 | 轴线 | 范围 | 驱动源 |
|---|---|---|---|---|
| 外环发动机机架 ×8 | 双轴 gimbal（2×revolute 串联） | `CSYS_ENG_LOCAL` 内/外环轴 | ±5° [⚠️假设] | TVC 作动器 ×2/台 |
| 中心发动机机架 | fixed | `AX_ENG_0` | — | 固定 |
| 栅格舵 ×4 | revolute | `AX_FIN_1..4` | ±20° [⚠️假设] | 旋转作动器 |
| **着陆腿主支柱 ×4** | revolute | `AX_LEG_1..4` | 收拢→展开 `ang_leg_deploy` | 气动撑杆 |
| **着陆腿撑杆 ×8** | revolute（上铰） | `AX_LEG_S_1..8` | 随动 | 气压 |
| **撑杆下铰 ×8** | revolute | `CSYS_LEG_LOCAL` 下铰轴 | 随动 | 从动 |
| **主支柱内筒 ×4** | prismatic（阻尼行程） | `CSYS_LEG_LOCAL` 柱轴 | 0→缓冲行程 | 着陆冲击 |
| 展开锁销 ×4 | prismatic（锁销） | `AX_LEG_LOCK_1..4` | 0→锁定 | 弹簧 |

**着陆腿耦合关系**：单条腿是**平面四杆机构**（箭体 + 主支柱 + 撑杆 + 上铰连线），自由度 1（展开角），但 CAD 里需约束 **5 个旋转副 + 1 个移动副**。

> ❌ 浅层写法：「4 条着陆腿各具备单自由度铰链展开」—— 漏掉 8 根撑杆、8+8 个铰接头、4 个阻尼移动副。阶段 3 装配时会发现撑杆无处可挂。

### 运动能力需求（只记录，不决定路线）

| 项 | 内容 |
|---|---|
| 是否需要运动能力 | 是——着陆腿展开与栅格舵偏转是本对象的核心功能，静态位姿无法验证干涉 |
| 需要哪一类 | 单向展开（着陆腿，收拢↔展开两个极限位姿）+ 有限摆动（栅格舵 ±20°、发动机 gimbal ±5°） |
| 已具备的前提 | joint 类型齐全、轴线 ID 齐全、四杆机构约束关系已写明 |
| 缺什么 | `ang_leg_deploy` 为 `[⚠️假设-待确认]`，展开中间位姿的撑杆长度需按实际铰点重算 |
| 默认交付 | 静态装配体（着陆腿收拢位姿 + 舵面 0° + 发动机 0°）。用户明确要求动画/URDF 时再按本表启动对应路线。 |
